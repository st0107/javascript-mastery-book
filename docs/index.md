# JavaScript Mastery for FAANG Interviews

This book teaches JavaScript as an execution model, not a bag of syntax tricks.

The goal is simple: when an interviewer asks what happens when JavaScript runs a piece of code, you should be able to explain the engine, memory, scope, stack, queue, browser or Node.js host behavior, trade-offs, failure modes, and production consequences.

## Reading Path

Start with [Volume 1: JavaScript Fundamentals](volume-1/README.md) for the foundation, then continue with [Lexical Scope and Closures](volume-2/chapter-01/01-introduction.md), [`this`, Call, Apply, and Bind](volume-2/chapter-02/01-introduction.md), [Prototypes and Inheritance](volume-2/chapter-03/01-introduction.md), and [Classes and Object Creation Patterns](volume-2/chapter-04/01-introduction.md) in Volume 2. Each authored chapter includes interview material; Volume 5 is planned as a dedicated interview preparation volume.

## What Makes This Book Different

- Every major concept is connected to internal behavior.
- Every chapter includes interview-ready explanations.
- Chapter assertion programs accompany independently runnable snippets; module lessons include their required files.
- Diagrams are written in Mermaid so they can be reviewed and versioned.
- Exercises include hints, solutions, complexity, and alternatives.
